# Amanar - BUILD IN PUBLIC....

GEOINT satellitaire sur le Sahel.

Amanar, c'est Orion en tamasheq,l'étoile qui sert à naviguer au Sahara.

Le projet analyse de l'imagerie satellite (optique, thermique, SAR) pour cartographier l'activité des groupes armés dans la bande sahélienne : camps, pistes, convois, signatures thermiques.

Work in progress.
